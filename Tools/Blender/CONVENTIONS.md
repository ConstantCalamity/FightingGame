# Blender → Unity art pipeline conventions

All art is generated by Python scripts run headless:

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P <script.py> -- <args>
```

## Units and axes
- 1 Blender unit = 1 metre. Z is up.
- FBX export: default axes (`axis_forward='-Z'`, `axis_up='Y'`), `apply_unit_scale=True`,
  `apply_scale_options='FBX_SCALE_ALL'`, no `bake_space_transform`. Unity imports with
  `bakeAxisConversion = true`, so roots come in without rotation.
- The raw import maps **Unity (x, y, z) = Blender (x, z, y)** (verified in game: a character facing
  Blender -Y arrives facing Unity -Z). The game turns both characters and map instances 180° about Y,
  so in play **Unity (x, y, z) = Blender (-x, z, -y)** — use that for layout markers.
  - Characters: authored facing Blender **-Y**; the game then turns them to face ±X.
  - Unity's fight camera sits at Unity -Z (Blender **+Y**, about y = +7..+13, z = 2.4) looking toward Blender **-Y**.

## Stage layout (maps)
- Fighters move along Blender X in [-8.5, 8.5] on the plane y = 0. Floor top is z = 0.
- Keep |x| ≤ 10, |y| ≤ 2.5 perfectly flat and clear.
- Camera side (Blender y > 2.5, |x| < 14) must stay open: nothing taller than 0.3 m there.
- Backdrop and set dressing go at y < -3 and at the sides (|x| > 10).

## Characters
- Model in A-pose, facing Blender -Y, feet on z = 0, origin between the feet.
- Armature object named `Rig`; root bone `root` at the origin. Deform bones only are exported.
- Bone local axes: Y along the bone, Z aligned to the character's forward (-Y world) where possible,
  so +X rotation bends a limb forward (hip/shoulder flexion, elbow flexion, spine forward bend).
- Animations are separate Actions on `Rig`, exported as FBX takes named `Rig|<Clip>`.
  Clip names: Idle, WalkFwd, WalkBack, Jump, Block, Hit, KO, Win, Light, Heavy, Special, Air.
- Attack clip timing must match `Assets/_Game/Data/Movesets.json` (startup / active / recovery, seconds, 30 fps).

## Textures
- PNG. Normal maps tangent space, OpenGL (+Y), which is Unity's convention.
- Mask map: R = metallic, A = smoothness (1 - roughness). Unity URP Lit `_MetallicGlossMap` layout.

## Output locations
- Characters: `Assets/_Game/Art/Characters/<Name>/` (FBX + textures)
- Maps: `Assets/_Game/Art/Maps/<Name>/` (FBX + textures + materials.json + layout.json)
- Source .blend files: `ArtSource/` (stored with Git LFS)
- Preview renders: `Logs/` (git-ignored)
